# ESP Verb Trainer

Mobile-first PWA zum Lernen spanischer Verben mit einem 4-Fächer-System.

- 54 Startverben mit Präsens-Konjugation
- Fach 1–4 mit Wiederholungsintervallen
- 👍 / 👎 Selbstbewertung
- fällige Karten und 10-Karten-Schnelltraining
- eigene Verben hinzufügen
- lokaler Lernfortschritt (localStorage)
- JSON Backup/Import
- offline-fähig via Service Worker

## GitHub Pages
In **Settings → Pages** als Quelle **Deploy from a branch**, Branch **main**, Ordner **/(root)** wählen.
